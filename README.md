# Data Encryption and Decryption Tool

## Objective
To develop a tool that encrypts and decrypts messages to protect sensitive information from unauthorized access.

## Key Features
- Encrypts text messages.
- Decrypts encrypted messages.
- Uses an encryption key for security.
- Provides a simple command-line interface.
- Demonstrates basic cryptography concepts.

## How It Works
1. User enters a message.
2. The program uses an encryption key.
3. The message is converted into encrypted text.
4. The encrypted message can be decrypted using the correct key.
5. The original message is displayed after successful decryption.
